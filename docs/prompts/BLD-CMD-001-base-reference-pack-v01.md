## Image-generation prompt

Create one clean 2x2 orthographic turnaround reference sheet for AI 3D reconstruction. Use the supplied image only as the exact design and massing reference. Depict the identical body-only Terran Command Centre structural shell in all four panels at identical scale and centered alignment: top left front elevation, top right back elevation, bottom left left elevation, bottom right right elevation. No labels, captions, text, border lines, or perspective. True orthographic views on a uniform neutral light-grey background with flat diffuse studio lighting and essentially no cast shadow. Preserve the approved stepped fortress massing, broad foundation slab, central raised command block, low wings, angular buttresses, broad recessed wall bays, and mounting pads. Approximate full scale proportions 70m wide by 55m deep by 35m tall. Uniform matte light-neutral clay material. This is the base shell only: no glazing, doors, tanks, pipes, vents, fans, lights, panels, antennas, dishes, railings, stairs, ramps, decals, surface graphics, small greeble, or loose objects. Favor unambiguous silhouettes and consistent geometry between all four views. Square image, 2x2 layout.

## Production note

The generated sheet is a controlled reconstruction aid, not a replacement for the approved concept. The resulting base mesh remains subject to scale, silhouette, watertightness, and receiver-fit review before approval.

Post-trial validation found that the base views disagree in silhouette height and vertical
centring. The completed Meshy/retexture output is retained because it was individually reviewed,
but this reference package must be regenerated before another paid base-generation task. See
`References/Terran/TER-KIT-001_reference-validation_v01.md`.
