## Shared prompt frame

Each call used the approved v04 sheet as a **design/style reference only** and requested one exact
component. The common prompt required:

> Create a clean 2×2 reference sheet of the same isolated component. Top-left is front, top-right
> is back, bottom-left is left and bottom-right is right. Do not print labels or other text. Show
> the identical object at identical scale and centre in all panels, with consistent features and
> complete silhouettes. Use orthographic/measurement presentation, flat neutral studio light, a
> uniform light-grey background, no ground plane and no cast shadow. This is one object, not four
> variations. No environment, people, glow, transparency, logos or decals.
